## 👋 What is QSTYX?

QSTYX is a **small team with large capability**. It turns raw problems into working systems, and it is the **machine** behind the ecosystem: the AI and automation muscle that MIT CODE LAB experiments with and MITLIVE ships.

> 🧭 **Ecosystem:** ⚙️ **QSTYX** (the machine) → 🧪 [MIT CODE LAB](https://mitcodelab.github.io/) (the workbench) → 🌐 [MITLIVE](https://mitlive.github.io/) (the catalog)

## 🛣️ Four lanes

| | Lane | What it covers |
|---|---|---|
| 🤖 | **AI & Automation** | Workflows, assistants, RAG, document processing |
| 💻 | **Software & Web** | Landing pages, dashboards, MVPs, API integrations |
| 💬 | **CX / CCaaS-adjacent** | Conversational workflows, chat design, CRM glue |
| 🔧 | **Digital Operations** | Process redesign, tooling, systems integration |

## 🔀 The Signal Path

`📥 Input → 🔍 Discover → ✏️ Design → 🔨 Build → ✅ Validate → 🚀 Deploy → 🔁 Improve → 🎯 Outcome`

Eight stages from raw problem to useful outcome. We listen before we architect.
